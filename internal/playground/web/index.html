What you are watching

Claiming

Workers claim rows with SELECT … FOR UPDATE SKIP LOCKED. Each PENDING task is claimed by exactly one worker.

Retries

Failed attempts are recorded in PostgreSQL and rescheduled with exponential backoff plus full jitter. The attempt counter is incremented on claim.

Heartbeat vs timeout

A handler timeout is an ordinary handler error. The reaper only acts when a RUNNING task stops refreshing locked_at — for example after the worker process dies.

Dead letters

Once attempts are exhausted, Dhara writes a dead_letters row. Retrying a DEAD task resets attempts and returns it to the ready queue.
